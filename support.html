Dragonwake Privacy Policy

Dragonwake Support

For help with Dragonwake, email mrcropsgame@gmail.com.

When contacting support

Please include the platform you are using, the game version shown on the title screen, and a short description of what happened. Do not send passwords, payment-card details, or other sensitive information.

Google Play testing

Install the test build while signed into Google Play with the same Google account that joined the test. If a newly published test build is temporarily unavailable, wait a few minutes and try the test link again.

Save data

Android save games and settings are stored locally on the device. Uninstalling the app removes that local app data.
